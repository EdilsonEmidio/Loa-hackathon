# requisitos de sistema

1. o sistema terá uma tela de login com email e senha
2. o sistema não terá uma tela de registro
3. o sistema será dividido em 2 interfaces diferentes, uma para representante_escolar e outra para secretaria_educação
4. o usuario admin será capaz de transitar entre as 2 interfaces
5. a tela do representante_escolar terá as seguintes funcionalidades:
    - terá um card para cada pedido junto ao seu status
    - poderá filtrar os pedidos de acordo com o status
    - poderá criar um novo pedido que começará como em analise
    - não poderá editar um pedido
    - poderá cancelar um pedido
    - poderá ver os detalhes de um pedido
6. quando um pedido for confirmado, os protudos do pedidos serão considerados em estoque
7. poderá ser capaz de ver o estoque e dar baixa em algum produto do estoque
8. o restante será pensando depois
